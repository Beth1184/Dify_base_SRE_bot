# CPU 使用率过高排查手册

## 适用场景
当 CPU 使用率持续超过 80%，Prometheus 触发 cpu_usage_high 告警时，按本手册排查。

## 排查步骤

### 第一步：确认影响范围
- 登录 Prometheus（http://prometheus.internal）查看是单机还是集群范围
- 查看告警聚合面板，确认受影响实例数量

### 第二步：定位进程
- 执行 `top -bn1` 查看 CPU 占用最高的进程
- 执行 `top -Hp <pid>` 查看线程级 CPU 占用，定位具体线程

### 第三步：分析热点
- 执行 `perf top -p <pid>` 确认热点函数
- Java 应用执行 `jstack <pid> > jstack.log` 抓取线程堆栈
- 将线程 ID 转十六进制后与 jstack 中的 nid 对应

## 常见原因
1. Java GC 频繁 → 检查 JVM 参数与堆内存配置，观察 GC 日志
2. 日志打印过多 → 检查日志级别，定位高频日志输出
3. 死循环 / 正则回溯 → 检查近期代码变更记录
4. 流量突增 → 对比 QPS 曲线，判断是否需要扩容

## 应急处理
- 流量突增：按扩容流程申请扩容
- 代码缺陷：按回滚流程执行回滚
